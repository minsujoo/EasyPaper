# Paper Research Workspace

독립적인 데스크톱 Obsidian 플러그인입니다. 기존 앱 화면을 iframe으로 삽입하지
않고, 보관함·Scholar·히스토리·채팅·주석·단어장·복습·PDF/번역 읽기 화면을 Obsidian
구성요소로 직접 렌더링합니다. 설치된 로컬 연구 엔진을 플러그인이 직접 시작하며,
기존 데이터베이스와 Vault 내보내기 결과를 그대로 사용합니다.

현재 지원하는 기능:

- 생성 노트가 통합된 논문 보관함, 폴더 관리, 휴지통, 다중 PDF 드롭 가져오기
- OpenAlex·Semantic Scholar 융합 검색, 가로형 결과 목록, 폴더별 맞춤 추천,
  관심 평가, 유사 논문·BibTeX, Figure/Table 미리보기와 폴더 지정 공개 PDF 저장
- 읽기 달력과 마지막 페이지 책갈피
- PDF.js 원문·수식 렌더링 번역의 전 페이지 이어보기, 독립 스크롤 및 양방향 문장 이동
- 목차 섹션과 Figure/Table별 이동·크기 조절 설명 팝업
- 본문 인용 연결, 여러 학술 소스 검색, 인용 이유·개요, PDF 다운로드
- 드래그 선택 복사·하이라이트·단어장, 논문 채팅과 채팅/주석 모아보기
- Figure/Table 및 실험 흐름·키워드·용어집을 포함한 자동 노트와 Vault 동기화
- 논문 단어장, Anki 동기화와 간격 반복 복습

데스크톱 전용이며, 로컬 연구 엔진 패키지가 설치되어 있어야 합니다. 별도 GUI
프로그램을 시작하지 않고 플러그인이 엔진 프로세스의 수명과 인증 토큰을 직접
관리합니다.
